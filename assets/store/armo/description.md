Bring 3D Blockbench (.bbmodel) armors to Minecraft — No client mods required.<br><br>

Works as a desktop app (**Java 21**) to generate resource packs, or directly as a server plugin integrating with Nexo, ItemsAdder and CraftEngine via `/reloadAndSend`.

#### Features:
* • **Pure Vanilla Support:** Works out-of-the-box using optimized core shaders (zero client mods needed for players).
* • **Broad Compatibility:** Seamless fallback and support for EMF, OptiFine (CEM/JEM), and Iris shaders.
* • **Universal Entity Support:** Attach custom armor models to players and humanoid entities.
* • **One-Click Export:** Directly converts `.bbmodel` into game-ready assets and configs.
* • **Server Plugin Integration:** Seamlessly integrates with Nexo, ItemsAdder and CraftEngine via `/reloadAndSend`.
* • Tested and confirmed compatible with Minecraft versions 1.21.5 through 26.1, utilizing native 1.21.2 equippable components.
